# CareerSpark AI — Production-Oriented Full-Stack Development

**Tagline:** Turn Every Achievement Into Opportunity.

This is a full-stack web application designed for processing and publishing AI-enhanced professional achievements.

## Phase 1 Status
- Vite + React + TypeScript setup complete.
- Tailwind CSS and routing libraries installed.
- `.env.example` created.
- Project structure initialized.

## Setup Instructions
1. Copy `.env.example` to `.env` and fill in the required values.
2. Run `npm install`
3. Run `npm run dev` to start the local development server.

## Features to be implemented
- Supabase authentication & authorization
- Private image uploads & Gemini AI integration
- Social Media Publishing (LinkedIn, Meta)
- Approval and Workflow gates
